# JavaScript Error Handling

A focused introduction to error handling in JavaScript (ECMAScript 2022). Covers the error type taxonomy, the `Error` object, `try/catch/finally`, extending the `Error` class with custom types, and handling errors in asynchronous code.

All module content is consolidated into a single notebook.
