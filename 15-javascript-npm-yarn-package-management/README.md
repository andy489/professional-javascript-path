# JavaScript npm/yarn Package Management

A practical guide to managing JavaScript dependencies using npm and Yarn — covering the package manager concept, everyday install/remove workflows, advanced scripting, publishing, and Yarn's zero-install architecture.

All modules are consolidated into a single notebook: [`javascript-npm-yarn-package-management.ipynb`](javascript-npm-yarn-package-management.ipynb)

## Modules

| # | Topic |
|---|---|

| 02 | Managing Packages with npm |
| 03 | Advanced Tasks with npm |
| 04 | Managing Packages with Yarn |
