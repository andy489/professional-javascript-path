# Professional JavaScript: From Foundations to Enterprise

A structured learning path covering JavaScript from core fundamentals through enterprise-grade architecture and patterns.

## Modules

| # | Module | Topics |
|---|--------|--------|
| 01 | [Foundations](./01-foundations/) | Types, scope, closures, prototypes |
| 02 | [Functions & Functional Patterns](./02-functions/) | HOF, currying, composition, immutability |
| 03 | [Async JavaScript](./03-async/) | Callbacks, Promises, async/await, event loop |
| 04 | [OOP & Design Patterns](./04-oop-patterns/) | Classes, SOLID, GoF patterns in JS |
| 05 | [Modules & Tooling](./05-modules-tooling/) | ESM, CommonJS, Webpack, Vite, Babel |
| 06 | [Testing](./06-testing/) | Jest, TDD, integration & e2e testing |
| 07 | [Performance](./07-performance/) | Profiling, memory, rendering, Web Workers |
| 08 | [Security](./08-security/) | XSS, CSRF, CSP, secure coding practices |
| 09 | [Enterprise Patterns](./09-enterprise-patterns/) | DI, CQRS, event-driven, microservices |
| 10 | [Node.js & Backend](./10-nodejs-backend/) | Express, streams, clustering, REST & GraphQL |

## Prerequisites

- Basic programming knowledge
- Familiarity with HTML/CSS

## How to Use

Each module contains:
- `README.md` — concept explanations and learning objectives
- `exercises/` — hands-on coding exercises
- `solutions/` — reference solutions
- `examples/` — runnable code examples
