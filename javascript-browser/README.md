# JavaScript in the Browser

A practical guide to the Document Object Model, event handling, and HTML form interaction using modern ECMAScript (ES2015–ES2022).

All five modules are consolidated into a single Jupyter notebook.

## Notebook

[javascript-browser.ipynb](javascript-browser.ipynb)

## Modules

| # | Topic |
|---|-------|
| 01 | Document Object Model Fundamentals |
| 02 | Working with the DOM |
| 03 | Event Handling Fundamentals |
| 04 | Mouse and Keyboard Event Handling |
| 05 | HTML Form Handling |

## Demo Projects

Each demo directory contains a `Before/` and `After/` snapshot of the Globoticket web application.

Open `index.html` from any `After/` or `Before/` directory in a browser to run the demo — no build step required.
