# 03 — Async JavaScript

## Learning Objectives
- Understand the event loop and call stack
- Work with callbacks and avoid callback hell
- Use Promises and Promise combinators
- Write clean async/await code
- Handle errors in async flows

## Topics
1. Event loop & concurrency model
2. Callbacks
3. Promises & chaining
4. Promise combinators (all, race, allSettled, any)
5. async/await & error handling
