# 01 — Foundations

## Learning Objectives
- Understand JavaScript's type system (primitives vs objects, coercion)
- Master variable scoping: `var`, `let`, `const`, hoisting
- Understand closures and the scope chain
- Prototype-based inheritance and the prototype chain
- `this` binding rules (implicit, explicit, new, arrow)

## Topics
1. Types & coercion
2. Scope & hoisting
3. Closures
4. Prototypes & inheritance
5. `this` & binding
