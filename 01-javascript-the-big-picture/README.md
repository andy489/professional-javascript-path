# JavaScript: The Big Picture

An introduction to JavaScript covering what it is, where it runs, how the language evolves through the ECMAScript specification, and practical next steps for continuing your learning. Suitable for developers new to JavaScript or anyone wanting a clear mental model of the language and its ecosystem.

## Contents

All four modules are consolidated into a single notebook:

- [`javascript-the-big-picture.ipynb`](javascript-the-big-picture.ipynb)

## Modules

| # | Title | Topics |
|---|---|---|
| 01 | Why JavaScript? | Definition, characteristics, dynamic vs. static typing, compiled vs. interpreted |
| 02 | Where Is JavaScript Used? | Browser, HTML/CSS/JS, frameworks, Node.js, package management, full-stack, cloud |
| 03 | How Is JavaScript Versioned? | Ecma International, TC-39, ECMAScript releases (ES1–ES2017+), polyfills, transpilers |
| 04 | Next Steps with JavaScript | Recap and suggested learning path |

## Usage

Open the notebook in JupyterLab or VS Code with the Jupyter extension. Run the first code cell to define `render_diagram`, then execute subsequent cells to display the diagrams.

```bash
jupyter lab javascript-the-big-picture.ipynb
```
