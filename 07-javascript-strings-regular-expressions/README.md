# JavaScript Strings and Regular Expressions

A practical guide to defining and creating strings, working with the String API, and applying regular expressions in JavaScript (ECMAScript 2022). The course builds three mini-apps: a currency converter, a string utility library, and a basic spell-checker.

All three modules are consolidated into a single notebook.

## Notebook

[javascript-strings-regular-expressions.ipynb](javascript-strings-regular-expressions.ipynb)

## Modules

| # | Title | Topics |
|---|---|---|
| 01 | Diving into String Definition | Quote styles, template literals, String.raw, special characters, Unicode, surrogate pairs |
| 02 | Achieving Tasks with the String API | isEmpty/isBlank, strict vs. loose equality, sorting, concatenation, substringing, .at() |
| 03 | Understanding and Applying Regex | Regex creation, flags, .match(), .replaceAll(), d flag, practical tips |
