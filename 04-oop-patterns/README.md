# 04 — OOP & Design Patterns

## Learning Objectives
- Apply SOLID principles in JavaScript
- Use ES6 classes and inheritance effectively
- Implement common GoF design patterns in JS
- Understand when to prefer composition over inheritance

## Topics
1. ES6 classes & inheritance
2. SOLID principles
3. Creational patterns (Factory, Singleton, Builder)
4. Structural patterns (Decorator, Proxy, Facade)
5. Behavioral patterns (Observer, Strategy, Command)
