# Building a REST API in JavaScript with Express

A practical course covering how to build a complete CRUD REST API using Node.js, JavaScript, and Express — from project setup through design principles and testing with Postman and curl.

All three modules are consolidated into a single notebook:

📓 [`javascript-express-building-rest-api.ipynb`](javascript-express-building-rest-api.ipynb)

## Modules

| # | Title | Topics |
|---|---|---|
| 01 | Introducing the REST API Stack | JavaScript, Node.js & Express overview; project initialisation |
| 02 | Setting Up the REST API Project | REST concepts, architecture, design principles, planning, data storage |
| 03 | Building and Testing the REST API | Full build walkthrough; Postman and curl testing |
