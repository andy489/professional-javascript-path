# JavaScript Performance Playbook

A practical guide to measuring and improving JavaScript application performance. Covers fundamentals, memory management and DOM optimization, and async execution patterns — with concrete techniques you can apply immediately.

All modules are consolidated into a single notebook: [`javascript-performance-playbook.ipynb`](javascript-performance-playbook.ipynb)

## Modules

| # | Topic |
|---|---|
| 01 | Understanding JavaScript Performance Fundamentals |
| 02 | Memory Management and DOM Optimization |
| 03 | Optimizing JavaScript Execution |
