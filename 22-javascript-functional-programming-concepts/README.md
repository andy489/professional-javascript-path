# Functional Programming Concepts in JavaScript

A practical guide to functional programming in JavaScript — covering what FP is, its core principles, essential built-in functions, advanced techniques like recursion and currying, and how modern frameworks apply FP ideas.

All modules are consolidated into a single notebook: **[functional-programming-concepts-in-javascript.ipynb](functional-programming-concepts-in-javascript.ipynb)**

## Modules

| # | Topic |
|---|---|
| 01 | What Is Functional Programming? |
| 02 | Explore Core Features of Functional Programming |
| 03 | Function Composition |
| 04 | Built-in JavaScript Functions |
| 05 | Advanced Concepts of Functional Programming |
| 06 | JavaScript Frameworks and FP |

## Demos

The [`01-functional-js-demos/`](01-functional-js-demos/) directory contains a browser-based JavaScript project for running functional programming examples. Open `index.html` in a browser and paste example files from `src/` into `src/script.js` to run them.

**Demo files by topic:**

- `src/CoreConcepts-M3/` — first class functions, pure functions, closures
- `src/BuiltInFunctions-M5/` — map, filter, flat, reduce examples
- `src/AdvancedConcepts-M6/` — recursion, higher-order functions, currying
